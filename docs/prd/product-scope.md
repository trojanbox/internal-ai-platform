# 功能清单

六大产品区域的功能盘点依据 D-017：**基础功能与增强功能全部纳入产品总体目标**。纳入目标只表示能力要在产品里出现，不表示由平台核心自行实现，也不表示首版交付。模块归属与首版优先级在骨架确认后另行规划。

作用域：每企业一套云端空间（D-020）。下表所有「共享」「分享」都只在本企业内生效。

## 1. 聊天与交互

| 类型 | 能力                                                                                                                                                                                                                      |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 基础 | 新对话、连续多轮、历史记录列表、会话命名/搜索/置顶/归档/删除；编辑消息、重新生成、复制与导出；Markdown/代码/表格/链接与引用展示；上传文件或图片、查看与下载生成结果；展示工具运行与操作反馈；插件卡片、表单、业务页面入口 |
| 增强 | 语音输入与对话；图片识别/生成入口；对话分享；多种内容专用预览；分支对话与会话收藏                                                                                                                                         |

归属原则：聊天与展示是平台核心；图像生成、语音处理、数据转换等能力可由工具或插件提供。

## 2. Agent 与模型

| 类型 | 能力                                                                                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 基础 | 配置可用模型、选择当前/默认模型；普通问答与多步骤 Agent 任务；连续使用对话上下文、处理附件；自动选择工具与手动指定插件；可见的工具使用过程、需要批准的操作确认；任务失败解释与继续处理 |
| 增强 | 不同任务模式；多模型使用偏好；模型用量与费用展示；可控的长期个性化上下文/记忆；研究模式、复杂分析与多步骤交付                                                                          |

归属原则：Agent 通用运行与工具调用是平台核心；网页搜索、深度研究、图像、专业数据分析、业务领域推理可由插件或工具交付，平台负责展示结果。

## 3. 插件管理

| 类型 | 能力                                                                                                                                                                                  |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 基础 | 插件目录、搜索、介绍、能力与适用环境标注；安装/启用/停用/卸载、版本状态与更新提示；个人插件；本企业共享插件；关联外部服务账户；查看插件可执行操作及所需授权；插件自定义页面与业务入口 |
| 增强 | 插件导入与配置向导；常用/推荐插件；多账户连接；插件兼容性与问题提示、安装更新记录                                                                                                     |

归属原则：管理、发现、启用与 UI 承载是平台职责；业务工具、完整工作流与可选节点编排始终由插件提供（D-012）。共享插件是本企业的能力供给，不跨企业，也不代表使用者获得插件内的个人凭据或数据权限。

## 4. 用户、组织与内容空间

| 类型 | 能力                                                                                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 基础 | 个人设置（语言、主题、偏好）、用户资料归属、模型与插件偏好；企业内团队/工作区；按项目/主题组织对话及相关文件与指令；个人与团队文件及生成成果的查看、搜索、下载、删除；控制内容可见范围 |
| 增强 | 可选择的长期记忆及查看/关闭；企业内项目分享与协作；个人模板与常用任务入口                                                                                                              |

归属原则：内容空间管理内容与项目的长期归属（D-023、D-024），一份内容只有一个归属；会话私有、协作只在项目内（D-025）；可见范围为私有/团队/企业三档（D-026）；成员离开与团队删除按 D-027 处理。详见 [module-content-space.md](module-content-space.md)。

## 5. 任务与运行管理

| 类型 | 能力                                                                                                                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 基础 | 当前 Agent 任务状态、运行进度与结果；停止/取消、失败反馈与可理解的重试或继续；工具调用或重要操作的确认；任务历史与结果回访；操作记录（谁、何时、哪个工具、哪个外部系统、结果）；任务通知或完成提醒入口 |
| 增强 | 任务列表中心；计划任务、周期执行、变化监测；长任务的暂停与继续；任务进度共享                                                                                                                           |

归属原则：平台处理通用 Agent 任务、云端多节点协调与平台层操作记录（D-022）；企业业务流程状态、业务流程日志和节点式工作流引擎仍归插件。操作记录不等于审批流或管理员审查界面。

## 6. 外部系统与能力连接

| 类型 | 能力                                                                                                                                                                               |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 基础 | 通过 MCP 直接连接或通过插件连接企业既有业务软件、文档/文件服务、邮件与日历、知识与搜索来源；在聊天中查询、读取、提交有授权的操作；展示来源、返回数据及执行成败；外部授权连接与断开 |
| 增强 | 网页检索、深度研究、电子表格分析、报表与文档生成、图片或音频处理、浏览器/电脑操作等专业工具能力                                                                                    |

归属原则：平台提供直接 MCP 与第三方连接及授权状态，连接与凭据按本企业空间归属（D-020）；插件提供特定业务规则、数据处理与工作流；Agent 调用两种来源的工具；不能假定第三方系统已有可用 MCP Server 或插件。

| ----- | ----------------------------------------------- |

| D-012 | 业务工作流与节点编排归插件                      |
| D-013 | Agent 自动选择工具 + 用户可显式指定             |
| D-014 | 员工可自行安装插件                              |
| D-015 | 云端个人插件与共享插件并存                      |

| D-018 | 仅云端产品，本地版不在范围内                    |
| D-019 | 直接 MCP 与插件双接入并存，插件可复用 MCP       |

| D-023 | 引入企业内团队/工作区，内容归属分企业/团队/个人 |

## 不在本清单的方向

本地独立部署版及两版本切换、迁移、同步；平台内置采购/人事/财务/审批流程；完整企业审批引擎；企业管理工作后台与管理员审查流程；跨企业插件市场或公开应用市场；跨机无缝任务恢复；强制流程工作台；凭据自动同步；任意企业软件零适配接入；全平台集中式业务数据仓库。
