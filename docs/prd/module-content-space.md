# 内容空间（区域 4）

区域 4 是「用户、组织与内容空间」，负责内容**归谁所有、谁能看见、人走之后去哪**。骨架与决定索引见 [product-baseline.md](product-baseline.md)。

当前状态：细化中。D-024～D-027 已确认，其余标注为建议或待细化。

## 1. 范围

| 负责                                                                                 | 不负责                                                                                                                                       |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 用户与个人设置；企业内团队；项目；文件与成果的长期归属；长期记忆；模板；内容可见范围 | 会话消息的展示与输入（区域 1）；推理与上下文使用（区域 2）；插件安装与能力（区域 3）；任务运行与操作记录（区域 5）；外部连接与授权（区域 6） |

会话的**归属**由本区域定义（D-024），会话的**界面**由区域 1 承载。

## 2. 实体

企业空间 > 团队 > 个人；项目挂在个人或团队之下；文件与成果挂在项目之下；长期记忆挂在个人之下。

## 3. 归属规则

| 内容       | 所有者       | 规则                                                                    |
| ---------- | ------------ | ----------------------------------------------------------------------- |
| 会话       | 个人         | 始终私有；可生成只读分享链接，不共同编辑、不共同继续（D-025）           |
| 项目       | 个人 或 团队 | 唯一的协作单元；一个项目只有一个所有者                                  |
| 文件与成果 | 跟随所属项目 | 不复制、不镜像；对话中生成的成果需用户显式保存到项目才进入空间（D-024） |
| 长期记忆   | 个人         | 不设团队共享记忆；默认仅当前项目生效，可改为跨项目（D-030）             |
| 模板       | 个人 或 团队 | 与项目同级，按同一可见范围规则处理                                      |

插件安装与外部连接的归属分别在区域 3、区域 6；它们可以授予个人还是团队，见 Q-019。

## 4. 可见范围

三档：**私有 / 团队内 / 企业内**（D-026）。

| 内容归属   | 可用档位                 | 默认     |
| ---------- | ------------------------ | -------- |
| 个人项目   | 私有、企业内             | 私有     |
| 团队项目   | 团队内、企业内           | 团队内   |
| 文件与成果 | 继承所属项目             | 跟随项目 |
| 会话       | 仅私有，另有只读分享链接 | 私有     |

- 调整可见范围的权限属于内容所有者，不引入管理员审批（D-022、D-026）。
- 单个文件的可见范围不得宽于所属项目。
- 分享链接是会话的只读快照，可撤销，不改变会话归属。
- 分享链接只在企业内生效：打开时必须登录且属于本企业，不提供匿名外链（D-028）。

## 5. 生命周期

| 场景         | 行为                                                                |
| ------------ | ------------------------------------------------------------------- |
| 成员离开团队 | 团队项目留在团队；个人私有内容不受影响（D-027）                     |
| 账号停用     | 个人私有内容归档，不移交他人（D-027）                               |
| 团队删除     | 进入回收期，成员可导出；不自动并入个人空间（D-027）                 |
| 项目归属变更 | 个人与团队之间双向转换，转换后按新归属的可见范围生效并留痕（D-029） |
| 删除会话     | 待细化；需明确任务与操作记录对会话的引用如何处理                    |

## 6. 关键流程

1. **对话成果落盘**：会话中生成结果 → 用户选择「保存到项目」→ 成果出现在目标项目 → 会话本身不因此获得项目归属。
2. **团队协作**：创建团队 → 邀请成员 → 建团队项目 → 资料、指令、成果都在项目内 → 成员按项目可见范围访问。
3. **分享会话**：打开会话 → 生成只读链接 → 本企业已登录成员可查看，不能继续对话或修改；链接可随时撤销。

## 7. 与其他区域的接口

| 区域                 | 关系                                                         |
| -------------------- | ------------------------------------------------------------ |
| 1 聊天与交互         | 上传附件、展示内容空间中的文件；会话列表展示个人会话         |
| 2 Agent 与模型       | 按当前任务读取被授权的项目资料与记忆；不获得长期归属权       |
| 3 插件管理           | 插件可用性入口需要知道当前是个人还是团队上下文（依赖 Q-019） |
| 5 任务与运行管理     | 任务成果回写到项目；操作记录引用内容时保留归属信息           |
| 6 外部系统与能力连接 | 连接与凭据按企业空间归属，不由本区域持有                     |

## 9. 非目标

企业管理工作后台与管理员审批、团队级审批流、跨企业分享与匿名外链、团队共享记忆、多人共同编辑同一会话。
